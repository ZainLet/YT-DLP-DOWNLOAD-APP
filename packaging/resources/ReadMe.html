Antes de instalar / Before installing

Esta versão usa assinatura local ad hoc. O aplicativo e o instalador não são assinados com Developer ID nem notarizados pela Apple. O macOS pode exigir sua autorização em Ajustes do Sistema → Privacidade e Segurança. Não é necessário desativar o Gatekeeper.

This release uses local ad-hoc signing. The app and installer are not Developer ID signed or Apple notarized. macOS may require your approval in System Settings → Privacy & Security. Disabling Gatekeeper is not required.

Dados e downloads / Data and downloads

A fila e o histórico ficam na memória e são apagados quando o app é fechado. Os arquivos baixados permanecem na pasta escolhida. Os links são acessados diretamente pelos sites de origem. Baixe apenas conteúdo que você tem autorização para salvar.

The queue and history are kept in memory and reset when the app quits. Downloaded files remain in the selected folder. Links are requested directly from the source websites. Download only content you are authorized to save.

Componentes / Components

Licenças e avisos estão em Contents/Resources/ThirdParty, dentro do app. As fontes correspondentes e instruções de compilação estão disponíveis na release do GitHub e no repositório.

Licenses and notices are included in Contents/Resources/ThirdParty inside the app. Corresponding sources and build instructions are available in the GitHub release and repository.
